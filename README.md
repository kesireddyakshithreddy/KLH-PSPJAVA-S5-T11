ABSTRACT:
(ATM Transaction Simulator with Zero Trust Security) With the rapid growth of digital banking and ATM services, the risk of fraud, credential theft, and unauthorized 
transactions has become a major concern.Traditional ATM systems often rely only on PIN‑based authentication, which is vulnerable to phishing,brute‑force attacks,and 
stolen card data. Once compromised, attackers can easily perform transactions without further checks.

To address these challenges, the proposed ATM Transaction Simulator integrates a Zero Trust security model that follows the principle of “Never Trust, Always Verify.”
The simulator combines core banking operations such as deposits, withdrawals, and balance inquiries with advanced security features like Multi‑Factor Authentication 
(MFA), email‑based One‑Time Password (OTP) verification, bcrypt password encryption, JSON Web Token (JWT) session management, device recognition, IP‑based 
verification, and detailed audit logging. 

This layered approach ensures that every transaction request is continuously validated before execution. An administrative dashboard allows monitoring of user activity,
detection of suspicious login attempts, and generation of security reports, while users can securely manage their accounts and view transaction history. By embedding 
Zero Trust authentication into the ATM workflow, the simulator enhances transaction security, minimizes fraud, and provides a scalable solution suitable for banking 
systems, financial institutions, and educational projects focused on cybersecurity in fintech

Problem Statement:   ATM systems are widely used for financial transactions, but most rely only on PIN authentication. This single‑factor approach is vulnerable to card 
skimming, shoulder surfing, phishing, and brute‑force attacks. Once a PIN is compromised, attackers can withdraw money or perform unauthorized transfers without further 
checks. There is a need for a secure, realistic simulator that demonstrates how modern Zero Trust security can be applied to ATM transactions

Objectives: 
● To design an ATM Transaction Simulator that integrates Zero Trust authentication principles.
● To implement Multi‑Factor Authentication (MFA) using password + OTP verification.
● To secure user credentials with bcrypt encryption and manage sessions using JWT.
● To add contextual checks like device recognition and IP verification before allowing transactions. 
● To provide an administrative dashboard for monitoring suspicious activities and generating reports. 
● To educate students and professionals on how Zero Trust can strengthen financial systems

Scope & Applications:   The simulator can be used by: 
● Banks and financial institutions to train staff on secure transaction handling. 
● Educational institutions as a capstone project demonstrating cybersecurity in fintech. 
● Developers and researchers to test new authentication methods in a controlled environment.
